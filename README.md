# 🎮 Coletânea de Jogos

Este projeto foi desenvolvido com o objetivo de criar uma plataforma simples e prática para consulta de jogos, possibilitando que o usuário encontre rapidamente informações sobre seus títulos favoritos.

A Coletânea de Jogos apresenta dados essenciais de cada jogo, como:
- 📌 Nome do jogo
- 🕹 Gênero
- 📅 Ano de lançamento
- 🖥 Plataforma
- 📝 Descrição

---

## 🚀 Sobre o Projeto

Este projeto foi iniciado a partir de uma ideia proposta pela **Alura**, durante estudos de programação, visando praticar o desenvolvimento web e manipulação de dados utilizando JSON, HTML, CSS e JavaScript.

Além de exibir a lista de jogos, o objetivo também é melhorar a experiência do usuário com funcionalidades de **pesquisa** e **organização do catálogo**, sempre buscando expandir o conhecimento em novas técnicas.

---

## 🧩 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  
- JSON para armazenamento dos dados  

---

## 📌 Funcionalidades

- 🔍 Sistema de busca por nome
- 📚 Catálogo de jogos detalhado
- 🆕 Possibilidade de expansão do banco de dados futuramente

---

## ✨ Objetivo Educacional

O propósito principal deste projeto é servir como aprendizado e evolução no desenvolvimento de interfaces web, organização de dados e boa prática de programação.
